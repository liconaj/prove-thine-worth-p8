# Prove Thine Worth (PICO-8)

An unofficial PICO-8 port of **Prove Thine Worth**, a game about a prince escaping a dungeon.

## Credits
Special thanks to [Sheepolution](https://github.com/Sheepolution) for creating the original [Prove Thine Worth](https://sheepolution.itch.io/prove-thine-worth).
This repository is an independent reimplementation of the original game for the [PICO-8](https://www.lexaloffle.com/pico-8.php) fantasy console.
